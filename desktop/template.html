点击任意「提交」节点查看详情（含完整 diff）。
灰/蓝/橙等色块为仓库、分支、作者节点，点击可展开/折叠；泳道图中点击提交圆点看作者与时间。
操作说明
缩放：Ctrl + 滚轮，或工具栏 − / +；适应窗口：按 F 或「适应」；重置 100%：按 0
平移：在画布上按住左键 / 中键拖动
筛选：顶部「作者 / 分支」勾选框，或在统计面板点击作者行
搜索：顶部搜索框（提交 / hash / 作者），实时高亮
详情：点击提交节点 → 右侧看文件清单与逐行 diff
模式：分支拓扑(E) / 仓→分支→作者(A) / 仓→作者(B) / 作者→仓(C) / 时间线(D)
导出：工具栏 SVG / PNG / JSON（导出当前视图）
切换 / 刷新：exe 下返回启动器或重新扫描；独立版打开 data.json 或重绘
